# 手動確認のチェックリスト

自動テストでは確かめられない、Tauri（ネイティブ）まわりと、見た目の確認項目です。リリース前に、`make dev` または `make app` で起動して確認します。

## ファイル

- [ ] `Cmd + S` で、保存ダイアログが開き、`.ideatree` の拡張子で保存される
- [ ] `Cmd + O` で、保存したファイルを開ける（`.json` も開ける）
- [ ] Finder で `.ideatree` をダブルクリックすると、IdeaTree で開く（アプリが起動していない状態 / 起動中の状態の両方）
- [ ] `.ideatree` のファイルに、IdeaTree のアイコンが付く
- [ ] `Cmd + Shift + O` で、最近使ったファイルが出て、`↑↓` `Enter` で開ける
- [ ] 最近使ったファイルを移動・削除してから開くと、エラーが出て、一覧から消える
- [ ] 未保存の変更があるとき、開く・閉じるで、確認が出る

## 自動保存

- [ ] 編集して 2 秒待ち、アプリを強制終了 → 再起動で、復元の確認が出て、復元できる
- [ ] 「復元しない」を選ぶと、次の起動では、確認が出ない

## 書き出し

- [ ] `Cmd + Shift + E` で、`.svg` `.png` `.pdf` の各形式で書き出せ、他のアプリで開ける
- [ ] 日本語のラベル・画像・アイコンが、書き出しに含まれる

## 編集・表示

- [ ] クリップボード: `Cmd + C` / `Cmd + V` で、他のアプリとテキストをやり取りできる
- [ ] `Cmd + F` で検索でき、一致したノードが見える位置まで移動する
- [ ] `Cmd + /` で、ショートカット一覧が出る
- [ ] ズーム・パン、ドラッグでのつなぎ替えが、滑らかに動く
- [ ] 画像・アイコン・色・フォントが、画面で正しく表示される
