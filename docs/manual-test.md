# 手動確認のチェックリスト

自動テストでは確かめられない、Tauri（ネイティブ）まわりと、見た目の確認項目です。リリース前に、`make dev` または `make app` で起動して確認します。

## ファイル

- [ ] `Cmd + S` で、保存ダイアログが開き、`.ideatree` の拡張子で保存される
- [ ] `Cmd + O` で、保存したファイルを開ける（`.json` も開ける）
- [ ] Finder で `.ideatree` をダブルクリックすると、IdeaTree で開く（アプリが起動していない状態 / 起動中の状態の両方）
- [ ] `.ideatree` のファイルに、IdeaTree のアイコンが付く
- [ ] `Cmd + Shift + O` で、最近使ったファイルが出て、`↑↓` `Enter` で開ける
- [ ] 最近使ったファイルを移動・削除してから開くと、エラーが出て、一覧から消える
- [ ] 未保存の変更があるとき、開く・閉じるで、確認が出る

## 自動保存

- [ ] 編集して 2 秒待ち、アプリを強制終了 → 再起動で、復元の確認が出て、復元できる
- [ ] 「復元しない」を選ぶと、次の起動では、確認が出ない

## 書き出し

- [ ] `Cmd + Shift + E` で、`.svg` `.png` `.pdf` の各形式で書き出せ、他のアプリで開ける
- [ ] 日本語のラベル・画像・アイコンが、書き出しに含まれる

## 編集・表示

- [ ] クリップボード: `Cmd + C` / `Cmd + V` で、他のアプリとテキストをやり取りできる
- [ ] `Cmd + F` で検索でき、一致したノードが見える位置まで移動する
- [ ] `Cmd + /` で、ショートカット一覧が出る
- [ ] ズーム・パン、ドラッグでのつなぎ替えが、滑らかに動く
- [ ] 画像・アイコン・色・フォントが、画面で正しく表示される

## テーマ・メモ・リンク・関連線・手動配置

- [ ] `Cmd + ,` の設定で、テーマ（自動・ライト・ダーク）を切り替えられる。自動のとき、システムの配色の切り替えに追従する。再起動しても、設定が残る
- [ ] ダークで、パネル・入力欄・ラベル・中心ノードの文字が、読みやすい。書き出した SVG・PNG・PDF は、白い背景のまま
- [ ] `Cmd + L` で、メモとリンクを付けられる。リンクの印、または `Cmd + Shift + L` で、既定のブラウザで開く（http・https のみ。`javascript:` などは、拒否される）
- [ ] `Cmd + R` で、離れた 2 つのノードを、矢印で結べる。同じ組で、もう一度確定すると解除される。書き出しにも含まれる
- [ ] ノードを、何もない場所へドラッグ、または `Cmd + Option + 矢印キー` で動かせる（枝ごと動く）。`Cmd + Shift + R` で、自動配置に戻る。保存して開き直しても、位置が残る
- [ ] `Cmd + Shift + 0` の全体表示で、大きなマップが、ちょうど収まる
- [ ] `.md` のアウトラインを書き出し、そのファイルを開き直す（取り込み）と、同じ木になる
- [ ] 先細りの枝の太さ・見た目が、好みに合っている（`src/domain/nodeGeometry.ts` の `TIP_RATIO` などで調整できる）
- [ ] `Shift + 矢印キー`・`Shift + クリック` で複数のノードを選べ（選択の見た目が分かる）、ドラッグ・`Cmd + Option + 矢印キー` で、まとめて動く。`Escape` で解除できる
- [ ] 関連線に、ラベルと色を付けられる（`Cmd + L` のパネルの「関連線」の欄）。書き出しにも反映される
- [ ] リンクとメモ入りのマップを、`.md` に書き出して、開き直すと、リンク（`[ラベル](URL)`）とメモ（`> ` の行）が、元に戻る
