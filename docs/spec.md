# IdeaTree 仕様書

## 1. プロジェクト概要
- **対象OS**: macOS
- **開発言語**: TypeScript (Frontend / React+Vite想定) + Rust (Backend / Tauri想定)
- **コンセプト**: トニー・ブザンが提唱するマインドマップの法則に忠実な、UIと操作性に優れた思考整理ツール。

## 2. コア機能要件（トニー・ブザンの法則に準拠）
1. **セントラルイメージ**: 中央から開始し、中心には画像または象徴的なビジュアルを配置できる。
2. **ブランチ（枝）**: 直線ではなく、有機的な曲線で描画されること。中心に近いほど太く、外側にいくほど細くなる。
3. **1ブランチ＝1ワード**: 枝の上に乗せる言葉は単語（キーワード）を基本とする。
4. **カラー**: メインブランチごとに異なる色を割り当て、カラフルな構成にする。
5. **強調と連想**: 自由なフォント選択、文字の大小、アイコンや画像の追加による視覚的強調を可能にする。
6. **保存・エクスポート形式**:
   - **JSON**: プロジェクトデータの保存と読み込み（再編集用）。
   - **SVG**: マインドマップのベクター画像エクスポート（曲線やカラフルな描画を劣化なく保存）。

## 3. 操作性（キーボードファースト）
マウスを使わずに思考のスピードを止めない操作性を実現する。マウスでも、ノードのクリック（選択）とダブルクリック（編集）ができる。

| キー | 動作 |
| --- | --- |
| `Tab` | 選択ノードの子ノードを追加し、テキスト入力を始める（折りたたまれていれば自動で展開） |
| `Enter` | 選択ノードの兄弟ノードを追加し、テキスト入力を始める（中心ノードでは何もしない） |
| `Shift + Enter` | 入力中に、ラベルの改行 |
| `F2` / ダブルクリック | 選択ノードのテキストを編集する |
| `→` / `←` | 最初の子ノード / 親ノードへ移動する（折りたたまれたノードでは子へ進まない） |
| `↓` / `↑` | 次の兄弟 / 前の兄弟へ移動する |
| `Delete` / `Backspace` | 選択ノードをサブツリーごと削除する（中心ノードは削除できない） |
| `Option + ↑` / `Option + ↓` | 兄弟の順序を入れ替える（1つ前 / 1つ後ろへ） |
| `Cmd + Option + 矢印キー` | 選択ノードと子孫を、20 ずつ動かす（手動配置。中心ノードは動かせない） |
| `Cmd + Shift + R` | 手動配置を、自動配置に戻す（選択ノードと子孫。中心ノードなら、すべて） |
| `Option + →` | 前の兄弟の最後の子にする（インデント。前の兄弟が折りたたまれていれば自動で展開） |
| `Option + ←` | 親の直後の兄弟にする（アウトデント。中心ノードの子になると、新しいメインブランチとして色が割り当てられる） |
| `Space` | 選択ノードの子孫を折りたたむ / 展開する |
| `Cmd + C` / `Cmd + V` / `Cmd + X` | サブツリーのコピー / 選択ノードの子としてペースト / カット（システムのクリップボード経由。後述） |
| `Cmd + Z` / `Cmd + Shift + Z` | 元に戻す / やり直す（最大 100 件） |
| `Cmd + B` / `Cmd + I` | 選択ノードの太字 / 斜体を切り替える |
| `Cmd + R` | 関連線: 選択ノードから、結ぶ先を矢印キーで選び、`Enter` で確定（すでに結んでいれば解除）、`Escape` で取り消し |
| `Cmd + L` | メモとリンクのパネルを開く / 閉じる（ノードに、補足の文章と URL を付ける） |
| `Cmd + Shift + L` | 選択ノードのリンクを、ブラウザで開く |
| `Cmd + K` | スタイルパネルを開閉する（色・フォント・文字サイズ・アイコン・画像）。色は、パレット、色コード（`#RRGGBB`、Enter で反映。空で「自動」）、色の選択ボタンで指定できる |
| `Cmd + Shift + I` | 選択ノードに、画像を選んで設定する（中心ノードなら、セントラルイメージ） |
| `Cmd + S` | JSON で保存する（保存先が決まっていれば上書き） |
| `Cmd + Shift + S` | 保存先を決めて JSON で保存する |
| `Cmd + O` | ファイル（`.ideatree` / `.json`）を開く。`.md` / `.txt` は、アウトラインとして取り込む |
| `Cmd + Shift + O` | 最近使ったファイルの一覧（`↑↓` で選び、`Enter` で開く、`Escape` で閉じる） |
| `Cmd + Shift + E` | SVG・PNG・PDF・Markdown アウトラインとして書き出す（保存ダイアログで選んだファイルの拡張子で、形式が決まる） |
| `Cmd + =` / `Cmd + -` / `Cmd + 0` | 拡大 / 縮小 / 拡大率と表示位置を元に戻す |
| `Cmd + Shift + 0` | 全体表示（マップ全体が収まるよう、表示を合わせる） |
| `Cmd + F` | ノードを検索する（後述） |
| `Cmd + ,` | 設定（テーマ: 自動・ライト・ダーク） |
| `Cmd + /`（`Cmd + ?` も可） | ショートカット一覧を開く / 閉じる（`Escape`、閉じるボタンでも閉じる） |

### 自動保存と復元
- **自動保存**: 未保存の変更があるとき、最後の変更から 2 秒待って、編集中のマップを、アプリのデータフォルダ（`~/Library/Application Support/com.toshiaki0315.ideatree/autosave.json`）に自動で書き出す（アトミックな書き込み。保存先のファイルは、変更しない）。編集していたファイルのパスと、時刻も一緒に保存する。
- **削除**: `Cmd + S` で保存したとき、保存した状態まで元に戻したとき、別のファイルを開いたとき、未保存の変更を破棄してウィンドウを閉じることを選んだときに、自動保存を削除する。
- **復元**: 起動時に、前回の自動保存が残っていれば（アプリが落ちた場合など）、「保存されていない、前回の編集内容が残っています（日時、ファイル名）。復元しますか？」と確認する。「復元する」を選ぶと、その内容で始め、保存していない変更として扱う（保存すれば、変更なしになる）。「破棄する」を選ぶと、自動保存を削除して、通常どおり起動する。
- 自動保存の読み書きに失敗しても、エラーは表示せず、編集は続けられる。確認のダイアログが失敗したときは、残っている内容を守るため、その回は自動保存しない。壊れていて復元できない自動保存は、無視する。

### 検索
- `Cmd + F` で、検索バー（画面の上部中央）を開き、入力欄にフォーカスを移す。検索語を入力すると、テキストに検索語を含むノードを、黄色く強調し（今の一致は、橙の縁取り）、「N 件中 M 件目」を表示して、今の選択以降の、最初の一致を選ぶ（なければ、先頭の一致）。一致がなければ、「該当なし」と表示し、選択は変えない。
- 検索は、大文字小文字を区別しない、部分一致。前後の空白は無視する。正規表現の記号は、普通の文字として扱う。中心ノードも対象。折りたたまれて見えないノードも、一致の数に含める。
- `Enter` / `Shift + Enter`（または、「↓」「↑」ボタン）で、次 / 前の一致へ移動し、端では、反対側へ回り込む。折りたたまれた枝の中の一致に移動するときは、祖先を展開して見せる（その展開は、1 手の履歴で、元に戻せる）。選択したノードが、見える範囲の外なら、自動でパンする。
- `Escape`（または、「閉じる」ボタン）で閉じる。選択は、見つけたノードのまま。スタイルパネル・ショートカット一覧とは、同時には開かない。テキスト編集中は、開かない。

### ショートカット一覧
- `Cmd + /` で、操作の一覧（キー・マウス操作と、その説明）を、グループごとに表示する。開いている間は、ノードの操作のショートカットは、効かない。スタイルパネルとは、同時には開かない。テキスト編集中は、開かない。内容は、`src/domain/shortcuts.ts` にまとめている（README と、この仕様書の一覧と、同じにする）。

### ズームとパン
- **拡大・縮小**: `Cmd + =`（`Cmd + +` も可）で 1.25 倍に拡大、`Cmd + -` で縮小（25%〜400%）。`Cmd + 0` で、100% と中心の位置に戻る。マウスホイールやトラックパッドで、`Ctrl`（ピンチ）か `Cmd` を押しながら回しても、拡大・縮小できる。拡大率が 100% でないときは、画面右下に表示する。`Cmd + Shift + 0` で、全体表示（表示の中心を、すべてのノードを囲む長方形の中心に合わせ、はみ出すときは、余白つきで収まるまで縮小する。小さいマップは、拡大せず 100% のまま）。
- **パン（表示位置の移動）**: そのままホイール・2 本指のスクロールを動かす、または、何もない場所を左ボタンでドラッグすると、表示位置が動く。
- **選択の追従**: 選んだノードが、見える範囲の端（40px 以内）や外に出たら、そのノードが中心になるよう、表示位置を動かす。
- 拡大率と表示位置は、表示だけの状態で、ファイルには保存しない。ファイルを開くと、元に戻る。SVG の書き出しにも影響しない。

### 画像
- **設定**: `Cmd + Shift + I`、またはスタイルパネルの「画像を選ぶ…」で、PNG・JPEG・GIF・WebP の画像を選んで、選択ノードに設定する。スタイルパネルの「画像を外す」で外す。設定・解除は、1 手の履歴になる。
- **表示**: 中心ノードの画像は、**セントラルイメージ**として、楕円の代わりに中心に描き、テキストは画像の下に置く（枠は 160×120。縦横比は保つ）。それ以外のノードの画像は、ラベルの上に小さく（64×48）描く。中心ノードに画像があると、ブランチは、その分、外側へずらして配置する。
- **大きさ**: スタイルパネルの「画像の大きさ」で、倍率（50%・75%・150%・200%・300%。「自動」は 100%）を選べる（`style.imageScale`、0.25〜4）。倍率を変えると、中心ノードの画像と枝の間の距離も、それに合わせて変わる。
- **制限**: 画像は 2 MB まで。SVG は、スクリプトを含められるため、対象外。画像は、データとして、JSON に埋め込んで保存する（ファイルが大きくなる）。コピー&ペースト、SVG の書き出しにも含まれる。

### アイコン
- IdeaTree の**オリジナルのアイコン**（絵文字ではなく、自作の SVG の図形。フラットで丸みのある、カラフルな絵）を、12 種類用意している: 重要（星）・完了（チェック）・注意（三角に!）・質問（?）・アイデア（電球）・目標（的）・期限（時計）・緊急（旗）・好き（ハート）・メモ（ピン）・調査（虫めがね）・お金（コイン）。
- スタイルパネルの「アイコン」で、絵の付いた一覧から選んで、選択ノードに付ける。「なし」（斜線の円）で外す。設定は、1 手の履歴になる。
- ブランチのアイコンは、ラベルの左側に、中心ノードのアイコンは、楕円（画像）の上に表示する（大きさは、ラベルの文字サイズの 1.1 倍）。コピー&ペースト、保存・読み込み、SVG の書き出しにも含まれる。SVG には、図形（パス）として出力するので、拡大しても劣化しない。
- ファイルには、アイコンの識別子（`star`、`check`、`warning`、`question`、`idea`、`target`、`deadline`、`urgent`、`heart`、`memo`、`research`、`money`）だけを保存する。選択肢にない値は、設定も、ファイルからの読み込みもできない（任意の文字列やデータは、保存しない）。
- 以前の版（0.5.5 まで）の、絵文字（⭐✅⚠️❓💡🎯⏰❗❤️📌🔍💰）のアイコンを持つファイルは、読み込むときに、対応する識別子へ自動で変換する。

### ノードの移動
- **マウスのドラッグ**: ノードを押して、4px を超えて動かすと、ドラッグが始まる（それ以下は、クリック）。別のノードの上で離すと、そのノードの子（末尾）につなぎ替える。ドラッグ中は、離すとつなぎ替えられるノードが強調表示される。つなぎ替えられないノードの上（自分自身・子孫・今の親）や、何もない場所で離すと、つなぎ替えは起きず、ノードと子孫が、ドラッグした量だけ動く（手動配置。ドラッグ中も、マウスについてくる）。中心ノードは、動かない。`Escape` でドラッグを取り消せる。左ボタンのみ。`Shift` を押しながら、兄弟のノードの上で離すと、つなぎ替えではなく、そのノードがあった位置に入れ替える（ドラッグ中の強調表示で、どちらになるかが分かる）。キーボードでは、`Option + ↑ / ↓` で入れ替える。
- 移動は、ノードを子孫ごと、木構造の中で移動する操作（自由な座標への移動はない。位置は、自動のレイアウトが決める）。
- 動かせないとき（先頭・末尾、前の兄弟がない、メインブランチのアウトデント、中心ノード）は、何もせず、履歴にも残さない。移動は 1 手の履歴になり、選択は移動したノードのまま。

### システムのクリップボードとの連携
- `Cmd + C` / `Cmd + X` は、サブツリー（折りたたみ・スタイルを含む）を、アプリの中と、システムのクリップボード（JSON のテキスト）の両方に保持する。システムのクリップボードに書けなくても、アプリの中のコピーは使える。
- `Cmd + V` は、システムのクリップボードを読み込んで、次のように貼り付ける。
  - **IdeaTree のサブツリー**（別のウィンドウでコピーしたものを含む）: 選択ノードの子として貼り付ける。貼り付けたノードを選択する。
  - **普通のテキスト**: 空行を除き、1 行 1 ノードで、選択ノードの子として追加する（最大 200 行）。最初に追加したノードを選択する。
  - **貼り付けられない内容**（空のテキスト、IdeaTree のサブツリー以外の JSON のように見えるテキスト、200 行を超えるテキスト）: 何もしない。
  - 読み込めたときは、システムのクリップボードを優先する。読み込み自体に失敗したときだけ、アプリの中のコピーを貼り付ける。
- 折りたたまれたノードに貼り付けると、自動で展開する。貼り付けは、1 手の履歴になる。

### テキスト編集中のキー
- `Enter`: 確定する。 `Escape`: 取り消す。入力欄の外をクリックすると確定する。
- Tab で追加した直後の空のノードは、空のまま確定するか `Escape` で取り消すと破棄される。
- 編集中は、上記のノード操作のショートカットは無効になる（入力欄のテキスト操作が優先される）。

### 設計上の判断
- 仕様の初版では `Enter` が「兄弟ノードの追加」と「テキスト編集」の両方に割り当てられていたため、**編集は `F2`（とダブルクリック）、`Enter` は兄弟ノードの追加**に統一した。
- 「元に戻す」の単位は、ノードの追加＋テキスト入力の確定を 1 手とする。矢印キー・クリックによる選択の移動、コピーは履歴に残さない。
- ファイルを開くと、元に戻す履歴は新しくなる（別の文書として扱う）。
- 編集中のテキストが入力欄にある間は保存・書き出し・ファイルを開く操作は無効（先に確定する）。
- **未保存の変更**: 最後に保存した（または開いた）時点のマップと違えば「未保存」とみなし、画面左下に「ファイル名 ● 未保存」と表示する（保存先がなければ「無題」）。保存したときの状態まで「元に戻す」と、未保存ではなくなる。選択の移動やコピーは、変更として扱わない。
- **ウィンドウを閉じるときの確認**: 未保存の変更があるときにウィンドウを閉じる（アプリを終了する）と、同じ確認ダイアログを出す。キャンセルするか、確認のダイアログが失敗したときは、閉じない。
- **ファイルを開くときの確認**: 未保存の変更があるときに `Cmd + O` を押すと、「破棄して続ける / キャンセル」の確認ダイアログを出す。キャンセルすると、ファイルを開かず、編集中のマップも変えない。

## 4. 開発プロセス・品質保証
- **開発手法**: TDD (Test-Driven Development)
- **カバレッジ目標**: ユニットテストカバレッジ 100% を目指す。最低要件として **95%** は必須。
- **例外規定**: UIレンダリング（特にSVG出力や曲線のピクセル調整など）やネイティブAPI（Rust側）の結合部分などで、テストの実装コストが非常に高い場合は、AI(Claude)から人間に「費用対効果の判断」を仰ぐこと。
- **構成管理**: GitHub (Public) にて管理。
  - リポジトリ: https://github.com/Toshiaki0315/IdeaTree.git

## 5. 描画の仕様
- **配置**: 中心ノードを原点に置く放射状レイアウト。最初のメインブランチは右向きの中心に置き、以降は時計回りに並べる。各ブランチは、含まれる葉（折りたたまれたノードは 1 枚）の数に比例した扇形を使う。ただし、メインブランチの子孫は、親ブランチの向きを中心に、扇形の幅を最大 120° までに収める（メインブランチが少なくても、子が親の後ろへ回り込まず、親と同じ向きに伸びる）。
- **ラベルの改行**: 入力中に `Shift + Enter` で改行を入れられる（`Enter` で確定、`Escape` で取り消し）。改行は、ノードのテキストに `\n` として保存し、必ず行を分ける。
- **ラベルの折り返し**: 長いラベルは、1行を「文字サイズの 10 倍」の幅（全角で 10 文字、半角で約 16 文字）までにして、複数行に折り返す。英単語は空白の位置で、区切れないときは文字の途中で折り返す。行の高さは文字サイズの 1.25 倍。折り返したあとの、一番広い行の幅と全体の高さを、クリック範囲・枝の長さ・アイコンの位置・SVG／PNG／PDF の出力（行ごとの `<tspan>`）に使う。編集中の入力欄は、1行のまま。
- **枝の長さ**: 親からの距離は、標準では 180px。ただし、ラベルが枝の上に入りきらないほど長いときは、枝を長くする（折り返したラベルの幅・高さとアイコンの幅を、枝の向きに投影した長さ＋余白）。横書きのラベルは、上下を向いた枝では、ほとんど長くならず、横向きの枝ほど長くなる。メインブランチは、中心ノードの外側に、ラベルが入る長さを取る。折りたたまれて見えない子孫のラベルは、影響しない。
- **ブランチ**: 親から子へ向かう、先細りの曲線（中心の線は三次ベジェ曲線の S 字）。根元の太さは深さが増えるほど細くなり（12px から、深さごとに 0.6 倍）、各ブランチは、根元から先へ向かって、根元の 0.4 倍（最小 2px）まで、なめらかに細くなる（Buzan のマインドマップの流儀）。塗りつぶした図形として描くので、SVG・PNG・PDF の書き出しも同じ見た目になる。
- **色**: メインブランチごとにパレット（8 色、白背景でのコントラスト比 3:1 以上）から割り当て、子孫は同じ色を引き継ぐ。色はメインブランチを作成したときに決めて、ノードに保存する（`branchColor`）。パレットのうち、最も使われていない色（同数ならパレット順で先頭）を割り当てるので、メインブランチを削除しても、他のブランチの色は変わらず、空いた色が次に使われる。
- **テキスト**: ブランチ上のテキストは、白い縁取り付きで置く。サブブランチは枝の中点に、メインブランチ（中心ノードの子）は、中心ノードの楕円（画像）と重ならないよう、その外側に出ている枝の部分の真ん中に置く。折りたたまれたノードは、ラベルの末尾に `…` を付ける。
- **スタイル**: ノードごとに、太字・斜体・色・フォント・文字サイズを設定できる。色は、そのノードの文字と、親から伸びる枝だけに効く（子孫には引き継がれない）。既定は標準の太さ。

## 6. ファイル形式
### 最近使ったファイルと関連付け

- 保存・開いたファイルのパスを、新しい順に最大 10 件、アプリのデータフォルダの `recent-files.json` に保存する（重複は先頭に寄せる）。読み込めない・書き込めないときは、無視して使い続ける。
- 一覧から開けなかったファイル（移動・削除済みなど）は、エラーを表示して一覧から外す。未保存の変更があれば、開く前に確認する。
- 標準の拡張子は `.ideatree`（中身は JSON と同じ）。`.json` も開ける・保存できる。バンドル設定（`fileAssociations`）で `.ideatree` を IdeaTree に関連付け、Finder から開くと、起動前は溜めておいて自動保存の確認のあとに、起動中は即座に開く（macOS の `RunEvent::Opened`）。

### JSON（`.ideatree` / `.json`、フォーマットバージョン 1）
```json
{
  "version": 1,
  "rootId": "…",
  "nodes": {
    "<id>": {
      "id": "<id>",
      "kind": "central | branch",
      "text": "…",
      "parentId": "<id> | null",
      "childIds": ["<id>", "…"],
      "position": { "x": 0, "y": 0 },
      "collapsed": true,
      "branchColor": "#RRGGBB",
      "image": "data:image/png;base64,…",
      "icon": "star",
      "style": { "bold": true, "italic": true, "color": "#RRGGBB", "fontFamily": "…", "fontSize": 20, "imageScale": 1.5 }
    }
  }
}
```
- `collapsed`、`branchColor`（中心ノードの直下のノードだけが持つ）、`style`、`image`（PNG・JPEG・GIF・WebP の base64 のデータURL。2 MB まで）、`icon`（アイコンの識別子）は省略可能。`style` の各項目も省略可能。`branchColor` のない従来のファイルは、ブランチの並び順から色を決める。
- 読み込み時は、次を検証し、不正なファイルは日本語のエラーメッセージで拒否する（編集中のマップは変更しない）。
  - JSON として正しいこと、`version` が対応済みであること
  - 各ノードの形式（`style` は、有効な項目だけを持つこと。未知の項目は拒否）
  - ルートが 1 つで親を持たないこと、`childIds` と `parentId` が互いに整合していること、ルートから到達できないノードがないこと、同じ子が `childIds` に重複していないこと、中心ノード（`central`）はルートだけで、ルートは中心ノードであること、座標が有限の数であること
- 読み込めるファイルの大きさは、最大 50 MB。
- 保存は、同じフォルダの一時ファイルに書いてから置き換える（保存の途中で失敗しても、元のファイルを壊さない）。

### 手動配置

- 自動配置の位置を、ノードごとに、手で動かせる。動かす操作は、何もない場所へのドラッグ、または、`Cmd + Option + 矢印キー`（20 ずつ）。中心ノードは、動かせない。
- 動かした量は、ノードの項目 `offset`（`x`・`y`。省略可）に、自動配置の位置からの**ずれ**として保存する。ずれは、そのノードと**子孫**に効く（子孫のずれは、親のずれに足される）ので、枝ごと、動く。自動配置が変わっても（兄弟を追加しても）、動かしたノードは、ずれを保ったまま、自動配置に付いていく。
- `Cmd + Shift + R` で、選択ノードと子孫のずれを、外す（中心ノードを選んでいれば、すべて）。元に戻す（`Cmd + Z`）の対象。SVG・PNG・PDF の書き出しにも、反映する。

### 関連線（`Cmd + R`）

- 親子とは別に、離れた 2 つのノードを、矢印（破線の曲線と、矢じり）で結べる。キーボードだけで操作する: 結ぶ元のノードを選んで `Cmd + R` → 矢印キーで結ぶ先のノードへ移動 → `Enter` で確定。すでに結んでいるノードの組で確定すると、向きによらず、解除する。`Escape`（または、もう一度 `Cmd + R`）で、取り消す。結ぶ先を選んでいる間は、ヒントを表示し、他の操作は効かない。同じノードのまま確定したら、結ばずに終わる。
- 関連線は、ファイルの項目 `relations`（`id`・`from`・`to` の配列。省略可）に保存する（フォーマットのバージョンは、1 のまま）。読み込み時は、端のノードが存在すること、同じノードを結んでいないこと、`id` と 2 ノードの組が重複していないことを、検証する。
- ノードを削除すると、そのノード（と子孫）につながる関連線も、なくなる。端のノードが、折りたたまれて見えないときは、描かない。
- 元に戻す（`Cmd + Z`）の対象。SVG・PNG・PDF の書き出しには、含める（ブランチの背面に描く）。アウトラインには、含めない。コピーしたサブツリーにも、含めない。

### メモとリンク（`Cmd + L`）

- ノードごとに、メモ（補足の文章。複数行、10000 文字まで）と、リンク（http・https の URL。2048 文字まで）を付けられる。ファイルの項目 `note`・`link`（省略可）に保存する（フォーマットのバージョンは、1 のまま。従来のファイルも読める）。
- パネルで入力し、フォーカスを外すか、閉じるときに確定する（1 回の確定が、元に戻す履歴の 1 件）。メモを空にするか、リンクを空にして確定すると、外す。
- リンクは、前後の空白を取り除き、スキームがなければ `https://` を補う。`javascript:`・`file:` など、http・https 以外は、エラーにする（保存データの読み込み時も、検証する）。
- 付いているノードには、ラベルの右に、印（メモ: 黄色の紙、リンク: 青い丸）を表示する。メモの印を押すとパネルが開き、リンクの印を押す（または `Cmd + Shift + L`）と、既定のブラウザで開く。Tauri の権限も、http・https だけに限っている。
- メモの内容も、検索（`Cmd + F`）の対象になる。SVG・PNG・PDF・アウトラインの書き出しには、含めない。

### 設定とテーマ（`Cmd + ,`）

- テーマは、自動（システムの配色に合わせ、切り替えにも追従する）・ライト・ダークから選ぶ。設定は、WebView の localStorage に保存する（保存できない環境では、その回だけ有効）。
- ダークは、画面の背景・パネル・中心ノードの文字（色を指定していないとき）が、暗い背景用の配色になる。枝の色は、どちらのテーマでも同じ。
- SVG・PNG・PDF の書き出しは、画面のテーマによらず、白い背景のまま。

### アウトライン（Markdown・テキスト）

- **書き出し**: `Cmd + Shift + E` で、拡張子が `.md` か `.txt` のとき。中心ノードが `# 見出し`、枝が `- 項目`（深さごとに、スペース2つのインデント）。ラベルの中の改行は、空白にする。折りたたまれたノードの子孫も、含める。
- **取り込み**: `Cmd + O` で、`.md`・`.markdown`・`.txt` を選ぶ。階層は、インデントで決める（スペース・タブ、何段でもよい。`- * + 1. 1)` の印は、あってもなくてもよい）。先頭の `# 見出し` が中心ノード。見出しがなければ、一番上の行が 1 つのとき、それが中心ノードで、複数なら、中心ノードは「中心テーマ」にして、それらをメインブランチにする。空行は無視する。行数の上限は 5000 行。
- 取り込んだ文書は、保存先のない、未保存の文書として開く（保存するときは、保存先を尋ねる。取り込み元は、上書きしない。最近使ったファイルにも加えない）。

### 書き出し（`Cmd + Shift + E`）
保存ダイアログで、SVG・PNG・PDF のいずれかを選ぶ。形式は、書き出すファイルの**拡張子**で決まる（`.png`、`.pdf`。それ以外、または、拡張子がない場合は、SVG として `.svg` を補う）。保存先は、JSON の保存先とは独立している。いずれも、画面と同じ描画規則で、表示されているノード（折りたたまれた子孫を除く）を、白い背景で書き出す。

- **SVG（`.svg`）**: ベクター画像。拡大しても劣化しない。
- **PNG（`.png`）**: SVG を、画面の 2 倍の大きさ（長辺が 8192px を超えるときは、収まる倍率）の画像にして書き出す。
- **PDF（`.pdf`）**: 1 ページの PDF に、JPEG 画像（品質 0.92）として載せる。ページの大きさは、画像を 96dpi の px として、pt（72dpi）にしたもの（ページ全体が画像のため、文字の選択や検索はできない）。

PNG・PDF は、WebView のキャンバスで描くので、フォントも画面と同じになる。
